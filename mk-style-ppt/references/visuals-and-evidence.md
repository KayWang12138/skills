# 图示与证据规范

需要行业或论文调研、生成配图、展示精度与性能数据时阅读。

## 将调研转成可读图示

先确定要解释空间分配、时序交叠、数据驻留、计算分解还是模型求值。查论文、官方文档和项目代码，核对图例、坐标与假设，不只模仿缩略图外观。

选择可迁移的图示惯例，不照搬结论，记录来源、适用条件及当前项目差异。精确架构和定量证据优先原生可编辑，建立直觉的示意可以图片生成。

| 概念 | 易理解的表达 | 避免 |
| --- | --- | --- |
| 核分配 | 二维 tile 网格、编号、核组与 lane 对应 | 无具体映射的抽象芯片光效 |
| 数据复用 | 访问序列、重复访问、复用距离、缓存驻留 | 无法读出复用的发光立方体 |
| 流水重叠 | 同一时间轴、资源行、区间与同步点 | 几条箭头宣称有掩盖效果 |
| 性能函数 | 有单位与条件的多系列曲线、拐点或误差 | 无坐标无含义的一条曲线 |
| 分层后端 | 分层主图配具体机制小图 | 抽象框图里再嵌另一幅同样抽象的框图 |

## 图片生成约束

提示中写明机制、对象身份和数量、空间或时间关系、因果方向、标签留白、长宽比、页面位置、低饱和与白底要求。

数据复用示例：展示 A、B、C、A 四次访问，在最后一次 A **之前**，比较容量为 2 和 3 个等大 tile 的驻留状态，假设全相联 LRU 和空初态。不能混成访问后的状态，也不能把教学例子当 SDCM 精度证据。

生成后检查顺序、连接、资源数量、驻留与科学关系。关键标签、数值、公式和复杂连接在 PPT 内原生编辑。严格可编辑的框架图不得用整张生成图片替代。

## 最小证据链

在工作材料中记录：**结论 → 数据或公式 → 原始来源 → 配置与适用范围 → 页内呈现方式。**

- PR / commit 中精度提升须回溯指标、样本和测试对象。口径不完整时标历史记录或待复验，不补造当前结论。
- 模型公式计算的数值注明预测或推导，不能混称真机验证。
- MAPE、APE 等保留对象粒度和统计范围，最大误差与平均误差不互换。
- 推导例子检查单位与算术关系。理想重叠、全命中或无通信等假设必须可见。
- 实测、预测与理论下界可同页展示，但用清楚标签和口径区分，不只靠颜色。
- 无真实数据时用机制图、变量公式或明确的教学算例，不用无来源数字制造数据支撑。

## 图的搭配

不用固定比例。连续多页框图时，在真正需要直觉的机制位置配示意图；不要每列塞生成图片或用装饰替换证据。

主图提供精确关系，小示意提供具体实例，用同一对象名或简短引导对应，不能无解释地引入另一套抽象。
